Measured timing

Start a test to measure rates.

Rates and mean timings use the latest ≈1-second window. Maxima and total overruns are since controller startup. An overrun means motor writes finished after the next tick was due. IMU ages measure time since receipt, not full sensor latency. PCB timing includes bus waiting. Lower waits and fewer overruns indicate more headroom; compare pose confidence and correction errors during the same movement. PCB rate is zero when PCB support is disabled.
